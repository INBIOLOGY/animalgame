# ระบบห้องเกมการ์ด 4 คน (Socket.IO + Express)

โปรเจกต์ระบบห้องเกมการ์ดและมินิเกม รองรับทั้งการเล่นหลายคน, เล่นกับคอมพิวเตอร์ (Bot), และโหมดแข่งกับเวลาคนเดียว (Solo Time Attack) พัฒนาด้วย Node.js, Express และ Socket.IO

---

## 📌 สรุปโหมดการเล่น (Game Modes)

1. **👥 โหมดหลายคน (Multiplayer Mode)**:
   - รองรับผู้เล่น 2-4 คน สามารถสร้างห้องหรือใช้รหัสห้อง 6 หลักเพื่อเข้าร่วมได้

2. **🤖 โหมดแข่งกับบอท (Vs 3 Bots Mode)**:
   - สำหรับผู้เล่นที่ต้องการเล่นคนเดียวร่วมกับคอมพิวเตอร์ 3 ตัว (บอท 1 🤖, บอท 2 🤖, บอท 3 🤖)
   - Host สามารถกดเพิ่มบอทลงในห้องหลายคนเพิ่มได้ หรือสร้างห้องโหมดบอทโดยตรง

3. **⏱️ โหมดแข่งกับเวลาคนเดียว (Solo Time Attack Mode)**:
   - ผู้เล่นเดี่ยวเปิดห้องเล่นคนเดียวแข่งกับนาฬิกานับถอยหลัง (เลือกเวลาได้: 30, 60, 90, 120 วินาที)
   - มีมินิเกมเปิดการ์ดจับคู่สะสมคะแนน real-time พร้อมสรุปคะแนนหลังหมดเวลา

---

## 📌 สรุปจุดที่มีการปรับปรุง (Key Changes)

### 1. ฝั่ง Server (`server.js`)
- **Validation & Sanitization**: ตรวจสอบชื่อผู้เล่น (1-16 ตัวอักษร) และป้องกันชื่อซ้ำในห้องเดียวกัน
- **Ack Callbacks**: ตอบกลับผลลัพธ์ทันทีเมื่อ Client ส่งคำขอ `create_room`, `join_room`, `add_bot`, `start_game`
- **Grace Period (15 วินาที)**: รักษาสถานะผู้เล่นเมื่อหลุดเน็ตชั่วคราว พร้อมขึ้นสัญลักษณ์ "หลุดชั่วคราว"
- **Bot System & Score Events**: เพิ่ม event `add_bot`, `submit_score`, `finish_game`

### 2. ฝั่ง Client (`public/index.html`)
- **Mode Selector UI**: ปุ่มสลับโหมดง่ายดาย (👥 Multiplayer / 🤖 Vs Bot / ⏱️ Time Attack)
- **Interactive Card Board**: กระดานเกมเปิดจับคู่การ์ดไอคอน real-time พร้อมตัวนับเวลาถอยหลังและตัวนับคะแนน
- **XSS Protection**: ใช้ `escapeHtml()` ป้องกันการแทรกสคริปต์อันตราย

## 🚀 วิธีการติดตั้งและรันโปรเจกต์

1. **ติดตั้ง Dependencies**:
   ```bash
   npm install
   ```

2. **เริ่มทำงาน Server**:
   ```bash
   npm start
   # หรือ
   npm run dev
   ```

3. **เข้าใช้งานผ่าน Browser**:
   - เปิดบราวเซอร์ไปที่ `http://localhost:3000`
